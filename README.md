# Packet Quest

A pixel-art RPG for studying **CCNA 1: Introduction to Networks**.

**Play:** https://brandon-hines.github.io/packet-quest/

- 17 realms, one per course module. Walk into monsters to fight them: every attack is a question.
- Missed questions come back more often. The Library tracks mastery and drills weak spots, and there is a 30-question practice exam.
- Endless generated problems for binary/hex, subnetting, IPv6 compression, ports and TCP vs UDP.
- **Console Lab:** a Cisco IOS command-line simulator that teaches from zero (Learn → Practice → Challenge).

Controls: arrow keys / WASD to move, Space or E to interact, 1–6 to answer, Esc for the menu. Progress saves in your browser.

Personal study project. Course questions come from Cisco Networking Academy material, which belongs to Cisco.
